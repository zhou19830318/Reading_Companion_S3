# 小白泽主题（2026-11-24）

依据：设计稿 [小白泽主题电子书.png](../小白泽主题电子书.png)（仓库内 9 屏效果图）。
状态：**第四版完成，真机竖屏复核通过**。全局组件、特殊页面接入与阅读状态栏已落地；本轮按反馈替换了裁切插画、去掉固定时段问候，并按真机截图修正了页眉排布。

## 第二版需求与验收

- 小白泽是整套界面的视觉语言，不是仅首页放一张形象图。所有设备页面共用黑白、圆润描边、轻量纸卡、气泡标签与清晰焦点样式。
- 页面标题、列表、标签页、菜单、按键提示、输入框、键盘、弹窗、阅读状态栏都由主题层统一绘制；特殊页面接入必要的主题钩子，不复制业务逻辑。
- 字体使用设备已有字体：标题适度加粗，正文清楚，辅助信息降低一级；中文沿用现有 CJK 支持，不引入大型字库，不修改用户的书籍正文字体。
- 禁止以 `...` 或 `…` 代替按钮名称、菜单值或加载状态。操作采用真实短标签；状态说明正在做什么；长标题优先换行，列表选中项提供完整阅读空间。实际摘录的省略标记不属于虚假占位。
- 保留所有入口、列表分页、确认/取消语义与进度信息；不删减功能，不以插画替代真实状态。
- 仅在选择小白泽主题时采用新绘制，Classic / Lyra / RoundedRaff 保持原有样式。
- 仅使用 1-bit 图元与已有静态资源，不增加帧缓冲，不增加常驻堆分配。页面装饰不覆盖正文、二维码、棋盘、用户图片或睡眠封面。

## 设计边界

- 新增一套**可选**主题（设置 → 显示 → 界面主题 → 小白泽），不替换 Lyra / Classic，避免影响现有用户与截图基线。
- 只使用 1-bit 能力：无彩色、无动画、无新增帧缓冲；插画为静态位图。
- 首页保持现有信息架构：继续阅读卡片 + 全部快捷入口。设计稿的 4 个入口只是示意，固件仍有 11 个入口，因此不删功能，只把首页栅格改为四列。
- 首页问候不再带固定时段（原“早上好”在下午/晚上不成立，且设备时钟可能未校时），只保留标题与说明。

## 实现

- `src/components/themes/baize/BaizeTheme.{h,cpp}`：派生自 `LyraTheme`，覆写全局组件与首页钩子。
  - 首页 `drawHomeGreeting()`：电池（右侧）→ 完整吉祥物（右侧，128×128）→ 左侧标题（`STR_BAIZE_HOME_TITLE`，UI_12 粗体，最多两行）与说明（`STR_BAIZE_TAGLINE`，SMALL，最多两行），文字块在问候区内垂直居中。
  - 插画直接复用已在 AI 页面使用的 `MascotReadIcon`（`components/icons/mascot_read128.h`，128×128、1-bpp、预旋转 90°），不再从设计稿裁切。原 `baize_home.h` 与 `scripts/generate_baize_mascot.py` 已删除；无新增静态资源，无新堆分配。
  - 插画通过 `companion()` 按像素解码缩放绘制，首页与页眉共用同一张完整图，避免缩放位图缓冲。
  - `drawHeader()`：吉祥物徽标改为完整方图并垂直居中；标题在上、副标题紧随其下整块垂直居中（原实现把副标题画在 `rect.y`、标题画在下一行，真机上版本号跑到标题上方）；标题宽度预留 48 px 给右上角电量，修正长书名第二行压住电量百分比的问题。
  - `preferredHomeColumns()` 返回 4，首页快捷入口由 3 列变 4 列（11 个入口 = 3 行）。
- 全局组件：`drawHeader` / `drawSubHeader` / `drawTabBar` / `drawList` / `drawButtonHints` / `drawSideButtonHints` / `drawButtonMenu` / `drawHomeIconGrid` / `drawRecentBookCover` / `drawChoiceCards` / `drawPopup` / `fillPopupProgress` / `drawProgressBar` / `drawSurface` / `drawSystemMessage` / `drawReaderDecoration` / `drawHelpText` / `drawTextField`。
- `BaseTheme`：新增 `drawSurface`、`drawSystemMessage`、`drawReaderDecoration` 钩子；`drawProgressBar`、`drawHelpText` 改为虚函数；首页问候与栅格列数钩子保留默认实现，不影响其他主题。
- 特殊页面：`ConfirmationActivity`、`FullScreenMessageActivity` 接入系统消息卡；`BaseTheme::drawStatusBar` 预留阅读状态栏装饰（Baize 用 4 px 圆角竖条，不挤占文字）。
- `BaizeMetrics::values`：复制 Lyra 度量，`homeTopPadding` 176（容纳 128 px 插画与两段文字）。
- 注册：`UI_THEME` 追加 `BAIZE = 4`（追加在尾部，存量 settings.json 的 0–3 含义不变）；`SettingsList` 追加主题选项；`UITheme::setTheme` 增加分支。
- i18n：英 / 简中 / 繁中 3 个键（`STR_THEME_BAIZE`、`STR_BAIZE_HOME_TITLE`、`STR_BAIZE_TAGLINE`）；`STR_BAIZE_GREETING` 已删除，其余语言回退英文。
