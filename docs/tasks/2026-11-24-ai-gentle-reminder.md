# AI-08.5 温和提醒（2026-11-24）

对应 v4.0 §5.1 AI-08.5、M5。状态：**代码完成**；睡眠页视觉验证受阻（见下）。前置：[RP-03 本地建议](2026-11-24-reading-plan-rp03.md)、[RH-02/03 聚合与热力图](2026-11-23-reading-history-rh02-rh03.md)。

## 设计边界

- **只在睡眠页**出现一行，不在阅读中、不在首页弹任何东西；没有通知通道、没有声音。
- **默认关闭**，在 `设置 → 系统 → 阅读提醒` 显式打开。没有计划、时钟未同步、今日已跳过时什么都不画。
- 内容只用本地数据：进行中的第一条计划 + 当天聚合 + （有页数目标时）近 14 天均速；不联网、不调 AI。
- 文案：完成 → `今天已读 N 分钟，计划完成`；未完成 → `今天还差 N 分钟 · 21:00-21:30`（当天命中的第一段；无时段/时钟未同步时只报分钟）。

## 实现

- `lib/ReadingPlan/ReadingReminder.{h,cpp}`：纯整数决策（Hidden / Done / Remaining）。缺的分钟数向上取整（27:59 读 30 分钟目标 → 还差 3 分钟，不是 2），完成判定按总秒数而非分钟，避免“显示 0 分钟但没完成”。
- `CrossPointSettings`：`planReminder`（默认 0）、`planReminderSkipDay`（本地日序号，0 = 从未跳过）。`planReminderSkipDay` 在 `JsonSettingsIO` 手工读写，越界值归零；开关走 SettingsList 自动持久化。
- `SleepActivity::drawPlanReminderLine()`：默认睡眠页底部一行（UI_10 的 SMALL），在反色之前绘制，深色/浅色睡眠页都可见。只在默认睡眠页绘制；自定义图/封面/快速恢复不叠加文字。
- `ReadingPlanListActivity`：提醒开启时追加一行 `今日跳过提醒` / `恢复今日提醒`，确认键在“今天”与“从未跳过”之间切换，只在值变化时写 settings.json。
- i18n：英 / 简中 / 繁中 8 个键（`STR_PLAN_REMINDER*`、`STR_PLAN_SKIP_TODAY*`、`STR_PLAN_RESUME_TODAY*`）。
